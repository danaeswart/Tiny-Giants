# README images

Drop your images in this folder using **exactly these file names** and the main
[README](../../README.md) will pick them up. Any that are missing show as a broken image,
so add them (or delete the line in the README).

| File | What to put in it | Suggested size |
|------|-------------------|----------------|
| `banner.png` | Hero banner at the very top (logo + tagline, or a collage of the app) | 1600 x 500 |
| `logo.png` | Tiny Giants logo | 400 x 400 |
| `mockup-hero.png` | Device mockup: storybook shelf (child) next to the parent dashboard | 1600 x 1000 |
| `feature-storybook.png` | Child storybook shelf / open book | 1200 x 750 |
| `feature-game.gif` | A short recording of a game scene (blowing out the candle) | 800 wide |
| `feature-parent-dashboard.png` | Parent dashboard | 800 x 1600 |

| `feature-profiles.png` | Child profiles / add child | 800 x 1600 |
| `feature-pin-gate.png` | Parent PIN gate | 800 x 1600 |
| `moodboard.png` | Moodboard | 1600 x 1000 |
| `colour-palette.png` | Colour palette | 1600 x 400 |
| `typography.png` | Fonts: Poppins / DM Mono | 1600 x 600 |
